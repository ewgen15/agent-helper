# Принципи дизайну UI плагіна («Meal Genius»)

Обраний напрям: світлий пастельний стиль із прозорими картками та одним синім акцентом. Еталон: `design/mockup-meal-genius.html`, референс: `design/references/ai-meal-planner-recipe-keeper.webp`. Принципи сформульовані як правила для розширення стилю на нові компоненти (автор формулювань: Opus, 09.11.2026). Темна тема в макеті є лише експериментальним перемикачем і в продукт не входить.

## Токени (джерело: `:root` у макеті)

| Роль | Значення |
|---|---|
| Фон (градієнт, діагональ) | `#fde3d6` → `#ece4fb` → `#d9ebfd` |
| Картка | `rgba(255,255,255,.78)`, рамка 1px світла |
| Тінь | `0 10px 28px rgba(70,60,130,.14)` |
| Текст / другорядний / посилання | `#1b1d2a` / `#555b6e` / `#0857c9` |
| Акцент | `#0a66f0`, білий текст (~5:1) |
| Статуси | ok `#13703a`; помилка `#a4191b` на `#ffe0df` |
| Плитки | синя `#cfe4ff`, зелена `#cdf3dc`, лавандова `#e4d9ff` |
| Теги вузлів | text `#ffe6d6`/`#7d3b12`; instance `#ebe2ff`/`#4a2c9c`; component `#d9f6e3`/`#15602f`; frame `#dbe9ff`/`#174a94` |
| Шрифт | Nunito (кирилиця), запасний `system-ui` |

## Принципи

- **Кольори та ролі.** Тема завжди світла. **Акцент лише один**, `#0a66f0` з білим текстом: головна дія та активний стан (основна кнопка, активна вкладка, фокус). Решта кольорів пастельні й лише позначають категорії.
- **Поверхні та глибина.** Два рівні: фон і картка. Не вкладай картку в картку, групуй відступами.
- **Форма та щільність.** Вкладки, кнопки й теги мають форму пігулки (999px), картки мають радіус 12–16px. Відступи тісні: теги 2–8px, кнопки 6–14px, крок сітки 4px. Шапка й вкладки закріплені, гортається лише вміст усередині вікна 380×520.
- **Типографіка.** Основний текст 12–13px, метадані 11px. Числа в плитках великі й жирні, підписи малі. Ієрархію задавай вагою та кольором, а не новими розмірами.
- **Теги та статуси.** Кожен тип вузла має пастельну пару «фон + темніший текст». Новий тип отримує нову пару з контрастом ≥4.5:1. Рядок «done» приглушуй кольором (`#555b6e`), а не прозорістю.
- **Стани.**
  - hover: трохи щільніший білий фон картки або світліший відтінок акценту;
  - focus: видиме кільце 2px `#0a66f0` з відступом;
  - disabled: сірий фон і `#555b6e`, `cursor: not-allowed`, без opacity;
  - error: червона пара кольорів і текст-пояснення;
  - empty: картка з коротким текстом `#555b6e` і однією дією.
- **Доступність.** Контраст тексту ≥4.5:1. Стан не передавай лише кольором: додавай текст або іконку. Усе доступне з клавіатури. Мінімальна зона кліку близько 24px.

## Не роби

1. Не додавай другий яскравий акцент і темну тему.
2. Не приглушуй через opacity: страждає контраст.
3. Не роби гострих кутів, важких чорних тіней і непрозорих сірих поверхонь.
