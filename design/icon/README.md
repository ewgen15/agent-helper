# Іконка Agent helper

- `agent-helper-icon.svg` — повна версія 128×128 (капсула, очі, естафета); джерело для експорту.
- `agent-helper-icon-small.svg` — спрощена версія для 16–24 px (без капсули, великі очі).
- `agent-helper-icon-128.png` — растр 128×128 з прозорими кутами для Figma Community (експортовано через headless Chrome).
- Для Figma Community завантажуй PNG 128×128 як іконку плагіна.
- 64 і 32 px: повна версія `agent-helper-icon.svg`.
- 24 і 16 px: спрощена версія `agent-helper-icon-small.svg`; повна у 16 px лишається лише для порівняння.
