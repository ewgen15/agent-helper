# UI.live: нотатки до референсу для плагіна (380×520)

Файл: `ui-live-figma-plugin.webp`. Усі HEX-значення нижче — приблизні оцінки з зображення, не виміряні пікселі.

## 1) Що на зображенні
- Маркетингова сцена: кілька вікон плагіна «UI.live – Create. Share. Grow.», знятих під кутом на сірому фоні.
- Ліворуч головне вікно: пошук, аватар, випадаюче меню (My profile, Add new post, Account settings, Log out), сітка карток із лічильниками «160» і «320».
- По центру екран «Add new post»: заголовок, велика зона вставки, чорна кнопка Cancel.
- Праворуч і внизу: екран «Looks good?» з міні-дашбордом (чіпи +37.8% / −37.8%) і екран «Post details» з полями-пілюлями.
- Декор: 3D-плашки з градієнтними обідками та синя кругла кнопка «+».

## 2) Палітра (оцінка)
- Фон сцени: #8E8E90. Поверхні вікон: #EFEFF0 – #F4F4F5. Вкладені панелі: #E4E4E6. Лінії: #D0D0D3.
- Текст: #111111 основний, #6B6B70 вторинний.
- Акцент: #1F3BFF (синій: FAB, ободок аватара, лічильник «160»).
- Primary: #0B0B0B (чорна пілюля).
- Статуси: #1E9E5A (зростання), #E0412E (спад).
- Градієнти: #7C4DFF → #FF9A4D; #2F6BFF → #E040FB.
- Палітра холодна нейтральна. Теплота є лише в помаранчевих градієнтах.

## 3) Типографіка
- Характер: геометричний гротеск без засічок; тонкі підписи і жирний заголовок.
- Ієрархія на макеті: заголовок ~24–28px bold, підзаголовок ~14–16px, підписи карток ~13px medium, бейджі ~11px.
- Для 380px: заголовок 16–18px/600, основний текст 12–13px/400, бейджі 10–11px/600.
- Безкоштовні аналоги (Google Fonts, OFL): Plus Jakarta Sans, Figtree, Manrope; для тонших рядків Inter Tight.

## 4) Форма й ефекти
- Радіуси: вікно ~24px, картки ~16–18px, пілюлі 999px, FAB коло.
- Тіні м'які й широкі. Обводки 1px, без жорстких бордерів.
- Щільність низька: відступи 20–28px. Для 380px потрібно 8–12px між елементами і 12px padding.

## 5) Компоненти
Взяти:
- Пілюльні табуляції для «Виділення» / «Записи (N)».
- Лічильник-пілюля з тонким обідком для «Записи (N)».
- Картка-рядок із 1px обводкою і радіусом 12–16px (з меншим padding).
- Чорна пілюльна primary-кнопка як основна дія.
- Чіп зі стрілкою (зелений/червоний) як зразок для статусів new/done (кольори змінити).
- Випадаюче меню з іконками та розділювачами для згорнутого хедера.
- Поле вводу-пілюля висотою 28–32px.

Не брати:
- Великі заголовки 24–28px і зону вставки на півекрана.
- 3D-плашки, градієнтні декоративні фони, ротацію вікон.
- FAB як основний CTA: у 380px краще звичайна кнопка внизу.

## 6) Придатність для вікна 380 px
Оцінка: 3/5.
Стиль добре переноситься (пілюлі, м'які картки, чорна primary-кнопка, чисті лінії), але макет розрахований на широкий екран з великими відступами, тож щільність доведеться зменшити майже вдвічі. Палітра холодна, тому теплий характер треба додати через акцентний колір.

## 7) Три CSS-токени-пропозиції
```css
:root {
  /* 1. Колір: теплий, замість холодного сірого */
  --bg: #F4F1EC; --surface: #FFFFFF; --surface-2: #EFE9E1; --line: #E3DCD2;
  --text: #1C1A17; --text-2: #78716A;
  --accent: #E0673A; --accent-ink: #FFFFFF; --new: #2F6BFF; --done: #1E9E5A;
  /* 2. Форма і щільність */
  --radius-win: 16px; --radius-card: 12px; --radius-pill: 999px;
  --gap: 8px; --pad: 12px;
  /* 3. Тінь: м'яка, лише для випадаючих меню */
  --shadow-menu: 0 6px 16px rgba(28,26,23,.10);
}
```
