# Нотатки до референсів

## ai-meal-planner-recipe-keeper.webp

Три екрани мобільного застосунку «AI Meal Genius» (рецепти й план харчування).

- Фон: м'який пастельний градієнт (персиковий, лавандовий, блакитний), майже без різких контрастів.
- Картки: білі та напівпрозорі, великі заокруглення, легка тінь («скляний» ефект).
- Акценти: один яскравий синій для активної вкладки та головної кнопки; чорний для вибраного фільтра.
- Кольорові плитки з цифрами (блакитна, лавандова, рожева, зелена, жовта): тепла пастель, велика цифра і малий підпис.
- Теги й фільтри: компактні «таблетки» (All, Breakfast, Lunch), вибраний темний.
- Шрифт: округлий геометричний sans із виразними великими заголовками.
- Нижня навігація: плаваюча таблетка з круглими іконками.

Що можна взяти для плагіна: пастельний градієнт фону, заокруглені білі картки, кольорові плитки-лічильники, компактні теги-таблетки, один синій акцент.
