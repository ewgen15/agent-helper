# Нотатки: Lunara Story Reading App (lunara-story-reading-app.webp)

## 1) Що на зображенні
- Шість мобільних екранів у ряд на персиковому фоні: онбординг (hero з постерами), головна (пошук, банер, «Discover Stories»), деталі книги, сітка карток.
- Онбординг: великий серіф-заголовок, помаранчева кнопка «Start Reading», веєр обкладинок під кутом, картка-соцдоказ «4.9 / 1M+ readers».
- Головна: логотип + аватар, поле пошуку-«таблетка» з круглою помаранчевою кнопкою, градієнтний банер з книгою, точки-пагінація.
- Деталі: назад/share/bookmark у круглих кнопках, обкладинка, таби-сегменти «About Book / Chapter / Review», велика помаранчева кнопка «Read Book».
- Картки книг: обкладинка в сірому квадраті зі скругленням, назва, кількість розділів, маленька кругла стрілка-кнопка.
- Плаваюча нижня навігація: помаранчева кругла «домівка» + білий pill із трьома іконками.

## 2) Палітра (ОЦІНКА з вигляду, не з файлу)
- Фон сторінки (персиковий): ~#FFD2C2
- Поверхня екрана (кремова): ~#FFF8EE
- Вторинні поверхні (бежеві плашки, пошук, таби): ~#EFEBE1
- Текст основний: ~#1E1B18 (теплий чорний)
- Текст другорядний: ~#6B625A
- Акцент (помаранчевий, кнопки/стрілки): ~#F26B2E
- Акцент глибокий (градієнт банера): ~#B5471C → #7A2E14
- Зірка/рейтинг: ~#F59E2B
- Обкладинки (жовтий, червоний, синій) — це зображення, не токени.

## 3) Типографіка
- Характер: висококонтрастний елегантний серіф (схожий на Playfair Display); заголовки щільні, курсивні штрихи, тепло й «літературно».
- Ієрархія (приблизно): hero 36–40 px / 700; заголовок екрана 24–28 px / 600; назва картки 16–18 px / 600; основний текст 14–15 px / 400 з інтерліньяжем ~1.6; мітка/підпис 11–12 px / 500, великі літери дозволені.
- Безкоштовна альтернатива з Google Fonts: **Playfair Display** (найближча), або **DM Serif Display** (заголовки) + **Lora** / **Source Serif 4** (текст).
- Для плагіна (380 px): серіф лише для заголовка вікна й назв записів; для тегів і бейджів краще sans (Inter), щоб вони були читабельні при 11–12 px.

## 4) Форма й ефекти
- Радіуси: картки ~24–28 px; кнопки і поля — повні «таблетки» (999 px); обкладинки ~12–16 px; кнопки-іконки — кола.
- Тіні: майже відсутні; м'який світлий ореол (1–2 px темніший контур у кремовому), плавна тінь лише у плаваючої навігації.
- Градієнти: лише в банері (помаранчево-коричневий, діагональний) та легкий фон.
- Blur: не помітний; «скло» немає.
- Бордери: тонкі світлі/білі, майже без ліній.
- Щільність: помірна-висока для мобільного; відступи 16–20 px по боках, 12 px між картками, 8 px у межах картки.

## 5) Компоненти для плагіна
- **Таби-сегменти** (сірий трек, білий/кремовий активний сегмент, pill) — ВЗЯТИ: ідеально під «Виділення / Записи (N)».
- **Кнопки-таблетки** (помаранчева заливка, висота ~36–40 px, стрілка-іконка) — ВЗЯТИ як основну дію; для компактності висота 28–32 px.
- **Круглі іконні кнопки** (сірі кола 32–36 px) — ВЗЯТИ для згортання заголовка/налаштувань.
- **Картки-рядки записів** (кремова картка, радіус 16–20 px, без тіні) — ВЗЯТИ з обрізаною висотою.
- **Теги/бейджі**: у референсі тегів майже немає — НЕ брати як приклад; для статусів new/done брати з іншого референсу (кольорові таблетки-пігулки).
- **Веєр обкладинок, банер, онбординг-hero, рейтинг-картка** — НЕ брати: займають надто багато місця для вікна 380×520.

## 6) Придатність для вікна 380 px
Оцінка: **4 з 5**.
Причина: палітра «тепла, компактна, без зайвих тіней» і таби-сегменти лягають у вікно майже ідеально. Мінус: референс орієнтований на великі картинки й відступи, тож потрібно ущільнити радіуси й типографіку вдвічі меншою щільністю.

## 7) Пропоновані CSS-токени
```css
:root {
  --lunara-bg: #FFD2C2;          /* персиковий фон вікна/рамки */
  --lunara-surface: #FFF8EE;     /* кремова поверхня картки/рядка */
  --lunara-accent: #F26B2E;      /* помаранчевий акцент: кнопки, активний статус */
  --lunara-radius-pill: 999px;   /* таби, кнопки, поля пошуку */
  --lunara-radius-card: 16px;    /* рядки записів (у 380 px менше, ніж 24–28) */
  --lunara-font-serif: "Playfair Display", serif;  /* тільки заголовки вікна */
  --lunara-font-ui: "Inter", system-ui, sans-serif; /* теги, бейджі, текст */
}
```
