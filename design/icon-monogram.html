Концепт іконки плагіна «Copy Node ID → Claude»: символ «#» як ідентифікатор ноди, один знак, без тексту.

16 px: при зменшенні штрихи стають близько 1.5 px, і «#» лишається розпізнаваним на всіх трьох фонах. Точка-іскорка у 16 px стає майже крапкою, тому вона лише декоративна: найважливіший знак — сам «#».

Чому ця монограма

  • Найкраща читабельність на 16–24 px: товсті штрихи і великі просвіти між ними.
  • Один гліф: нічого не зливається, текст на іконці не потрібен.
  • Асоціація з ідентифікатором: «#» означає id або номер, що відповідає функції «Copy Node ID».

Ризик: іконка нічого не говорить про Claude чи AI. Зв'язок із Claude має передавати назва й опис плагіна.
