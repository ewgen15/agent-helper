# Версії дизайну плагіна

Тут зберігаємо знімки UI плагіна «Copy Node ID → Claude» по версіях, щоб можна було порівняти їх між собою.

- `v0.1/` — git-тег `v0.1`: UI до вкладки налаштувань і до потоку «спершу коментар».
- Файли `v0.1/ui.html` і `v0.1/manifest.json` взяті з тега через `git show`, без змін.
- Переглянути: `open design/versions/v0.1/preview.html` (показує UI з демо-даними, без Figma і сервера).
- У превью запити на localhost не пройдуть, це очікувано: сервера немає.
