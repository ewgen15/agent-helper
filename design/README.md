# design/

Візуальний напрямок для UI плагіна.

## Що де лежить

- `DESIGN-PRINCIPLES.md` — **принципи й токени обраного стилю «Meal Genius»**. Починай звідси, коли додаєш або змінюєш компонент.
- `mockup-meal-genius.html` — обраний макет (еталон). Відкривається в браузері, ніде не опублікований.
- `mockup-lunara-orange.html` — альтернативний теплий макет (не обраний, лишається для порівняння).
- `references/` — референсні скріншоти (назва: `<застосунок-або-тема>-<короткий-опис>.<ext>`) і нотатки до них.

## Референси

- `references/ai-meal-planner-recipe-keeper.webp` — основний референс (нотатки: `references/NOTES.md`).
- `references/lunara-story-reading-app.webp` — теплий помаранчевий (`references/NOTES-lunara.md`, оцінка 4/5).
- `references/ui-live-figma-plugin.webp` — Figma-плагін, холодна палітра (`references/NOTES-ui-live-figma-plugin.md`, оцінка 3/5).
